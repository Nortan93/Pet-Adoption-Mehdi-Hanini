# Pet Adoption Website

This project is an interactive and responsive web application designed to connect pets seeking homes with potential adopters. It features a full client-server architecture, enabling seamless user interaction and robust data management.

# Key Features

* User Account Management: Allows users to create accounts, log in, manage sessions, and log out securely.
* Pet Browse & Search: Users can browse available pets and search for animals based on specific criteria.
* Pet Submission: Provides a form for users to submit pets for adoption, requiring login and validating input.
* Dynamic User Interface: Features a responsive design with real-time date and time display in the header for an enhanced user experience.
* Data Persistence: User credentials and pet information are securely stored and managed on the server.
* Comprehensive Validation: Implements both client-side and server-side validation for all forms to ensure data integrity.

# Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Data Storage: Text Files
* Validation: Regular Expressions

# Setup and Installation

To get a local copy up and running:

1.  Clone the repository.
2.  Install Node.js and npm dependencies (e.g., `npm install express`).
3.  Run the server (e.g., `node server.js`).
4.  Access the application via your browser at `http://localhost:port`.
